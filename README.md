## Novel Horizon

**This project is a frontend web application designed as part of my university assignment. It serves as a platform for readers to access translated South-Asian novels. The goal is to create a user-friendly interface that allows users to explore, read, and appreciate literature from diverse South-Asian culture.**

### Features

-  **User Authentication**: Users can create an account and log in to access their fovurite novels.
- **User-friendly Navigation**: Easy access to different categories and novels.
- **Novel Details**: Each novle includes a brief description, author information, and translation details.

### Technologies Used

- HTML5
- CSS3
- JavaScript



### Usage
1.  Click on the "Login" button to create an account or log in if you already
2.  Browse through the different categories and select a novel to read.
3.  Use the search bar to find specific novels.
4.  Hover on the image to see the title and author.
5.  Click on the image or the title to view its detals and  read the novel.
